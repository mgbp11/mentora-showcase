# Mentora — iOS prototype showcase

A static gallery for the Mentora native SwiftUI iOS prototype. Every image is a
real screenshot captured from the app running on an iPhone 17 Pro simulator
(iOS 26.5), not a mockup.

Plain HTML and CSS, no build step. `index.html` plus `shots/`.

The app itself lives in the `Mentora-iOS/` folder of the Mentora project and
cannot run on the web; this page exists to share the work as a link.
